# Clinical Management System

A web-based Clinical Management System designed to help manage clinical operations through a structured application.

## Overview

This project is developed to organize clinical workflows and provide role-based access for different healthcare staff.

## User Roles

- Doctor
- Receptionist
- Pharmacist
- Lab Technician
- Admin

## Technologies Used

- **Backend:** Python, Django, Django REST Framework
- **Authentication:** JWT (JSON Web Tokens)
- **Frontend:** React
- **Database:** Verify the configured database in the project settings

## Key Features

- Role-based access for different clinical staff
- JWT-based authentication
- Admin module
- Organized frontend and backend structure

## Getting Started

1. Clone this repository.
2. Set up the Python virtual environment.
3. Install the backend dependencies.
4. Configure the required environment variables.
5. Run the Django development server.
6. Install frontend dependencies and start the React application.

Refer to the project configuration and dependency files for the exact setup commands.

## Project Purpose

This project demonstrates the development of a clinical management application using web technologies, authentication, and role-based access control.
